# Netflix Content Type Prediction

## Project Overview

This project uses machine learning to predict whether a Netflix title is a Movie or a TV Show.

## Dataset

The dataset contains Netflix titles with information such as:

- Type
- Title
- Director
- Country
- Rating
- Release Year
- Genres

## Technologies Used

- Python
- Pandas
- Scikit-learn
- OneHotEncoder
- Logistic Regression
- Random Forest

## Project Workflow

1. Load the Netflix dataset.
2. Select relevant features.
3. Encode categorical variables.
4. Split the data into training and testing sets.
5. Train classification models.
6. Evaluate model performance.
7. Compare model accuracy.

## Models Used

### Logistic Regression

Accuracy: 99.37%

### Random Forest

Accuracy: 97.10%

## Results

Logistic Regression achieved a higher accuracy than Random Forest on the test data.

| Model | Accuracy |
|---|---:|
| Logistic Regression | 99.37% |
| Random Forest | 97.10% |

## Conclusion

The project successfully predicts whether a Netflix title is a Movie or a TV Show.

Based on the test results, Logistic Regression performed better than Random Forest on this dataset.
